# Chat Realism Guide

## The rule: write behavior, not vocabulary
Slang dates fastest. Chat behaviors are timeless.

## Behaviors to use

| Behavior | What it looks like | What it gives the comedy |
|---|---|---|
| Burst typing | One thought split across 3-5 short messages, the point landing in the last | Built-in timing; every message can carry a beat |
| Crossed threads | Two conversations interleave and a reply lands on the wrong message | Misreads that escalate on their own |
| The ignored message | Something absurd gets no reaction; someone calmly returns to it several messages later | Deadpan delay |
| Late replies | An answer to a message from several lines ago | Realism, plus accidental double meanings |
| Typos and corrections | Typos left in; a correction that makes it worse | Human texture with no joke needed |
| Time gaps | Timestamps that jump (e.g. 4:26 PM to 4:31 PM) | A free "meanwhile" |
| Inside jokes | A reference set up early and reused with less context each time | Compression and payoff |
| Platform-native moments | Join/pin notices, role pings, voice-channel talk, slash commands, permission errors, audit-log entries | NOTABOT's home turf |

## Channel-specific rules (from analysing existing scripts)
- Burst typing is NOTABOT's primary tool. 2-4 short lines in a row under one name header.
- fatas gets the longest gaps between messages. When fatas does reply, it derails.
- ducky's panic escalates in steps: ellipsis → lowercase panic → CAPS → silence.
- The `#!typing` sound is used specifically for "someone is about to say something that changes everything."
- `WELCOME CharacterName` is rare — maximum once per script, only when a new character's arrival is itself the joke.

## Rules of thumb
- Each character gets at most one verbal tic of their own.
- Mostly lowercase, loose punctuation, fragments. ALL CAPS is rare and earned.
- Vary message length hard: one word, then a long burst.
- Not every message is a joke. A beat of ordinary chat makes the punchline land.
- People don't answer the question they were asked, don't say each other's names in every line.
- Someone goes quiet, then lands one line late.
- Friend test, line by line: would a real friend send this exact message in this form? If it reads like a written joke, rewrite it.

## What the old examples taught and must be unlearned
- Every message a complete quip
- Everyone answering the previous line in order
- ALL CAPS panic as the default
- Exclamation marks everywhere
- Characters naming their feelings
- Filler like "bro what"
- Jokes that explain themselves
- Messages of uniform length
